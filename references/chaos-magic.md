# Chaos Magic Correspondence

Eleventh framework for Abraxas Orchestra (v0.1 corpus expansion). Preferred **secondary overlay** when multiple primary maps compete.

These mappings are design references. They guide paradigm switching, intent compression, banishing/reset, and results gating. They are not runtime ritual instructions.

| Operation | Traditional emphasis | Architectural role | Mechanical |
|-----------|---------------------|-------------------|------------|
| Paradigm shift | Belief as tool | Framework / paradigm select | `paradigm_switch` |
| Sigilization | Compress intent | Intent token | `intent_token` |
| Banishing | Clear residual state | Context reset | `context_reset` |
| Results magic | Judge by outcomes | Eval gate | `outcome_gate` |

- Outcome gates pair with Brier / score modules on Tree Tiphareth or alchemical Citrinitas.
