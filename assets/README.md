# Assets

| File | Use |
|------|-----|
| `hero.jpg` | Repository hero / README banner |
| `hero-full.jpg` | Higher-resolution variant (optional) |

Place the Abraxas Orchestra key art at `assets/hero.jpg` for README rendering.

```bash
# From repo root, after saving the art file:
cp /path/to/Abraxas-Orchestra-hero.jpg assets/hero.jpg
git add assets/hero.jpg
git commit -m "assets: add hero image"
git push
```
