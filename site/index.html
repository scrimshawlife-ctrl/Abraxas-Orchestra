What this is

Orchestra is a local Hermes + OpenClaw coding-agent skill that organizes software the way traditional systems organize meaning — Tree of Life, alchemy, runes, planetary spheres, I Ching, Solomonic ranks, Peircean signs, Numogram, sacred geometry, Enochian, Chaos Magic.

1. Scaffold

Emit dual-named project skeletons (mechanical + symbolic) from a chosen map, with provenance.

2. Diagram

Write HTML, JSON, and Mermaid architecture graphs next to the skeleton or analysis.

3. Analyze → optimize

Observe import graphs, map when the fit is honest, plan renames — write only with --confirm.

Not a network service, magic runtime, or silent auto-refactorer. Weak or forced mappings fail closed. You stay in control of filesystem changes.

Install

git clone https://github.com/scrimshawlife-ctrl/Abraxas-Orchestra.git
cd Abraxas-Orchestra
bash scripts/smoke.sh
bash install.sh --dry-run
bash install.sh                          # → ~/.hermes/skills/orchestra
# OpenClaw:
# bash install.sh --target ~/.openclaw/skills/orchestra

After install, the host discovers the skill from SKILL.md (name: orchestra).

Day-to-day commands

python3 scripts/orchestra.py list
python3 scripts/orchestra.py structure -f tree-of-life -c "intent,synthesis,output" --out /tmp/orch-skel
python3 scripts/orchestra.py diagram -f numogram --out /tmp/orch-diag
python3 scripts/orchestra.py analyze --path /path/to/pkg -f tree-of-life --out /tmp/orch-an
python3 scripts/orchestra.py optimize --from /tmp/orch-an/analysis.json --out /tmp/orch-plan
python3 scripts/orchestra.py optimize --from /tmp/orch-an/analysis.json --apply --confirm

Mapping strengths: STRONG ADEQUATE WEAK FORCED — weak/forced fail closed so agents do not paper over bad fits.

Multi-language analyze

LanguageFidelity
PythonFull AST import graph
JavaScript / TypeScriptToken + structured import/export/require nodes
GoToken + structured import declarations
RustToken + structured use / mod
RubyToken + structured require / require_relative
autoUnion of the above extensions

Non-Python resolution is best-effort (import-surface only, not full compilers). Optimize apply remains Python-oriented. 

python3 scripts/orchestra.py analyze --path . --lang auto --out /tmp/orch-an

Safety & quality gates

Local

Stdlib-only CLI · no network for structure/analyze/optimize · install path jail · optimize requires --confirm

CI

ci-ok requires version parity, path-jail, integrity floors, smoke, and coverage-gate. Soft coverage is informational.

main branch

PR required · ci-ok required · enforce for admins (no status bypass) · no force-push.

python3 scripts/orchestra.py check
python3 scripts/bump_version.py check
python3 scripts/integrity_check.py
python3 scripts/coverage_report.py --gate
